# GitHub Secrets Reference

Dokumen ini mencatat variabel rahasia yang terdaftar pada GitHub Secrets untuk keperluan CI/CD pipeline tanpa mencantumkan nilai asli.

| Secret Key | Description | Environment Used |
|---|---|---|
| `JWT_SECRET` | Secret key untuk penandatanganan dan verifikasi token JWT | Test / CI |
| `TEST_DB_URI` | String koneksi basis data khusus untuk pengujian otomatis | Test / CI |
